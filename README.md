# 记忆旅人

政治与历史像素卡牌学习游戏。静态页面，无须构建或安装依赖。

## 本地使用

将整个目录放到静态服务器；打开 `index.html`。项目包含 `index.html` 和 `curriculum.js`，部署时二者应位于同一目录。

## GitHub Pages

将文件上传至仓库根目录，在 GitHub 仓库 Settings → Pages 中选择 `Deploy from a branch`、分支 `main` 和目录 `/ (root)`，保存。具体可用性取决于 GitHub 账号及仓库设置。发布后 Pages 的内容可能对互联网公开。页面中的本地进度以浏览器与网站域名分别保存，不会跨域或跨设备自动同步。

课程内容仍未覆盖全部教材；学习时应结合教材核对。
